# Regional World V3：双 C 绕城与连续主线

基于本地保存的 V2 工作区迭代，未读取 GitHub 版本。最终地图包含 13 条高速、21 个真正互通枢纽、12 个普通出口、4 处服务设施。2026-10-11 完成一次最终 BasicValidation 构建并发布 playable dist。

## 主线与线路归属

- 保持此前已恢复的 G17 东临连续走廊、G38 北岭连续走廊：旧扩展段的内部道路 ID 不再决定显示编号，主线穿过新增枢纽仍属原高速。独立的 G42 晨江、G65 云岭继续承担西部区域过境功能。
- 删除机场、城际、沿江两端原有四个“continuation”式跨编号硬接节点，改成实际有匝道连接的互通。没有新增跨编号的主线直接接续。
- S12 改名西南绕城高速。保留原西侧—西南—南侧主体及既有西川、物流、东南枢纽，重建机场附近起端，并向西原和东部区域外延伸。
- 新增 S29 东北绕城高速，串联西北—北—东北—东侧—东南外圈。S12、S29 都是开放 C，两端错开，不闭环，也没有两条线首尾相接的枢纽。
- S18 机场高速保留原机场主线，接入 S12 曲线主线上的机场南枢纽。S36 通过错开设置的机场南城际疏解枢纽接入 S12，形成组合疏解节点，而非三条线头碰头。保留一个未启用的机场配套方向逻辑接口，不创建虚假可通行连接。
- S31 北端向沿江北部区域外延伸；南端主线经沿江南枢纽继续向南部区域外延伸。按用户最新意见，原南端折返完整保留为晨江东枢纽的 S31 → G17 回转联络匝道，约 5.1 km，具有实际道路、支撑及双端路网连接。折返与相邻右转匝道共用接收合流鼻端，G17 继续向东贯穿。
- 西侧优先延长现有 G42、S27、S12、S36；G65 北端外延。不再新增额外西侧高速编号。

## 枢纽与路面

保留既有十个真正互通；本轮新增或替换十一处：机场南、机场南城际疏解、北岭沿江、晨江东、东北绕城西、沿江北、北岭北、晨江东北、东临东、新城东、沿江南。

机场弯道节点采用不对称定向连接；斜交节点按真实曲线主线布置定向匝道，东北绕城西采用苜蓿叶连接。几何相交不会自动产生路网边；未连接的跨线处提供高度分离和桥墩。主线端部均在枢纽外延伸。

本轮为新连接生成加减速过渡，采用更长的端部曲线拟合，保留三角导流区、实虚线和车道箭头；当前地图共有 303 条辅助车道。修正沿江南枢纽夹角、机场局部匝道自交和折返跨线净空，端部连接平顺过渡。清除新道路范围内冲突的区域扩展树木；原城市对象不变。

## 路牌与加载

依据最终路线归属重新生成引导数据，沿用绿底门架主牌、常规字重的大字排版、路线盾牌、目的地及距离组织。右侧分流箭头按驾驶路径表达，直行用向上箭头，不按目的地地图左右决定。普通出口保留 2 km / 1 km / 500 m / 临近分流预告；互通、入口、里程、服务设施牌随新连接同步更新。最终有 1100 个门架牌记录，按距离延迟创建。

延续既有附近 sector 完整加载、远景道路与大型结构简化、共享静态资源及统计机制。本轮针对新增西侧/东北侧区域复核卸载、重载、路面接触和互通/桥梁预加载。首次初始化自测只编译 4 条道路、创建 1 个路牌，没有同时创建整个区域地图。此为自动化运行统计，不等于浏览器真实帧率或硬件加载耗时结论。

## 修改文件

本轮源文件与脚本：

- `src/world/regional/RegionalDoubleCRevision.ts`：本地 V2 → V3 可重复路网修订配方。
- `src/world/regional/regional-main.json`：最终地图与高速、节点、引导数据。
- `src/world/regional/HighwayData.ts`：未启用预留连接元数据。
- `src/world/regional/HighwayValidation.ts`：后续修订继续检查编号、归属、角色、端部数据。
- `src/world/regional/HighwayMarkings.ts`：可配置过渡端部拟合长度，既有调用保留默认值。
- `src/world/regional/HighwaySystem.selftest.ts`：双 C、外延、归属、保留折返及导引/加载定向检查。
- `src/world/city/presets/PresetGeometryValidation.ts`：保留完整上下文的目标道路检查，空间索引加快几何验证。
- `scripts/revise-regional-double-c.mjs`：生成并验证 V3 地图。
- `scripts/validate-regional-double-c.mjs`：对比本地 V2，只检查本轮新增或改变的道路并记录基线问题。
- `scripts/inspect-regional-geometry.mjs`：互通局部诊断包含邻接节点和辅助车道真实连接上下文。
- `artifacts/highway-system/draw-route-map.py`：十三色线路图、节点、图例、折返联络匝道。

输出：`artifacts/highway-system/highway-route-map.png`、`v2-baseline.json`、`v3-metadata.json`、`v3-geometry.json`、`test-results.json`、`v3-*-test.log`、`v3-typecheck.log`、`v3-build.log`、本报告，以及 `artifacts/regional-world/test-results.json`。诊断过程中 `artifacts/regional-world/interchange-geometry.json` 为原始宽范围诊断；本轮最终几何结果以 `v3-geometry.json` 为准。

已有城市、车辆、输入、车机和物理工作区改动未由本轮修改或丢弃。此前 RegionalWorld 自测适配继续用于本轮验证。

## 可接受残余与人工体验

- 本地 V2 的未改路段在扩大的几何诊断上下文中已有 67 条基线诊断记录，含同一走廊重复项，涉及旧路曲率、接入、重叠/净空等；记录在 `v3-geometry.json` 的 `baselineIssues` 中。本轮没有把这些既存问题算作通过，也没有扩展任务去重做未改道路。新/改路段及其与旧路的相交关系通过本轮检查。
- 构建仍有大型资源块警告，主资源约 15.7 MB（gzip 3.9 MB）。附近对象延迟创建已验证，但网络下载、JSON 解析及真实首次进入的感受仍需浏览器体验，后续可继续专项优化。
- 请人工体验机场弯道组合枢纽、沿江南枢纽及保留的 S31 折返：检查驾驶视角下的引导提前量、尺度、坡道视觉和路线自然程度。自动检查验证的是连接与几何约束，未做主观驾驶调校。
- S18 城市侧逻辑预留接口未启用；两条绕城及其它外联端点以区域外接续解释，本轮没有生成地图外城市。
