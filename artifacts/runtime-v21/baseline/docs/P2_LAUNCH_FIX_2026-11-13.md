# P2 混动刹车后起步失效修复 — 2026-11-13

## 根因与复现

坦克500踩刹车挂 D、松开刹车再加速时，`BrakeSystem.brakeInput` 的液压压力按指数逐步释放，数值不会立刻精确归零。P2 原实现只判断换算后的 `brakeMotor > 0`，因此即使残余压力已经小到 `1e-63`，仍选择回收分支，覆盖正向电机扭矩请求。它不是电池没电或电机未安装。

修复前真实固定步复现：P 挡踩 80% 刹车 1 s → 踩刹车挂 D 并停留 0.5 s → 松刹车、60% 踏板加速。EV 在 8 s 后只有 **0.4993 m/s（1.80 km/h）**，在 0.5 m/s 回收淡入阈值附近反复失去电驱。Sport / Charge 可以靠发动机继续拖动，但电机扭矩逐渐趋近零。直接初始化 D 挡、不先刹车的旧专项无法暴露此问题；旧专项在修复前仍能全部通过。

## 修改

- `src/vehicle/powertrain/P2HybridPowertrain.ts`：回收模式选择必须对应当前制动意图，不能由任意非零残余液压压力触发。当前踩刹车，或无加速请求而存在有效服务制动需求（含巡航制动），仍保留回收优先；残余液压阻力继续由真实制动系统施加。
- 同步使用该意图判断限制发动机发电分支，避免用已经松开的制动压力绕过发电请求限制。
- 未把液压压力强制清零，未提高电机/电池功率，未改变 SOC、车速、轮胎抓地或发动机标定；ABS 最终限额与机械制动融合不变。
- 新增 `src/vehicle/P2HybridLaunch.selftest.ts`、`scripts/run-p2-launch-selftests.ts`。覆盖踩刹车选挡再加速、五种混动模式、R 挡、EV 刹停再起步、刹车/油门同时输入和低 SOC 接管。
- 新增 `scripts/smoke-p2-launch.cjs`，通过最终生产桌面入口、实际车型选择和键盘链路检查 EV 挂挡起步、刹停后再次起步，不修改运行物理状态。
