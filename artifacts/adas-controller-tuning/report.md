# LKA / LCC 控制优化与 LDW 声音

本轮没有修改车辆动力学、转向物理、手柄映射、道路数据或 LaneObservation 结构。LKA/LCC 继续使用共享的合法车道观测，仅输出受限转向需求。LDW 声音接入沿用同一份观测。

## 控制策略

原控制器已有横向误差、航向和预瞄偏移；预瞄航向之前仅用于有效性检查。现在显式参与 LCC 航向反馈，并扣除弯道自身的切线变化，避免把道路弯曲当作驾驶误差。

横向速度按道路坐标计算：speed × sin(headingError) + bodyLateralVelocity × cos(headingError)。它包含车辆航向造成的侧向运动，也包含车身侧滑；经低通滤波后用于显式阻尼。LCC 预瞄偏移也加入车身侧滑的预计位移。

LKA 从预测边界风险启动，随后恢复到靠近该侧边界的内侧安全位置，不要求回到车道中心。车已向内回转时保留速度与偏航阻尼，等位置、航向、横向速度和偏航趋势稳定后平滑退出，避免一松辅助就漂向另一侧。对应方向转向灯、强驾驶员输入、车道变化和无效观测会清除恢复过程。恢复中的反向稳定转向仍显示原先被保护的边界。

LCC 保留几何曲率及原有欠转向前馈，增加连续小误差反馈、预瞄反馈和运动阻尼。反馈速度因子由 60 km/h 的 0.85 平滑升至 120 km/h 的 1.2；原有速度相关物理敏感度换算仍保留，避免把增益直接放大到高速轮角。输出幅值、变化率、驾驶员优先、释放等待和渐进重接管均保留；LCC 在退出或接管时也继续遵循自己的变化率限制。

## 对比验证

同一组车辆、现有物理和合法车道夹具，固定 120 Hz、几何观测 30 Hz，每场景 10 秒。对比误差为末 3 秒横向误差 RMS，单位 m。场景以 120 km/h 起始，末速受正常动力学及原有巡航路径影响，约 110–117 km/h；控制器单独测试也覆盖固定 120 km/h 输入。下面数值来自 before.json / after.json。

| 车型 | 高速直线：修改前 → 后 | 高速轻弯：修改前 → 后 |
|---|---:|---:|
| BMW 530Li | 0.118 → 0.020 | 0.338 → 0.216 |
| Tesla Model 3 RWD | 0.111 → 0.014 | 0.448 → 0.427 |
| A6L-like | 0.153 → 0.001 | 1.298 → 0.572 |

LKA 120 km/h 轻微右偏场景：明显辅助出现时间从 1.25–1.275 s 提前至约 0.067 s；起始辅助时车辆中心距边界约 1.17 m。最小车辆中心边界距离分别从 0.030 / -0.103 / 0.168 m 改善到 0.838 / 0.840 / 0.795 m，未发生车辆中心越线，且没有反复跨中心的左右摆动。这里统计的是车辆中心距离，不表示所有车身边缘都有相同余量。

通过的验证：40 项 LKA/LCC 控制及状态检查、19 项 LDW 触发检查、5 项独立声音调度检查、27 个实际车辆动力学短场景。覆盖 100/120 km/h 直线、小初始偏移、100/120 km/h 轻弯、左右边界接近、强驾驶员接管、有限辅助及变化率限制、无效观测和重接管。强转向场景验证驾驶员命令完整保留；驾驶员主动驶出合法车道后系统可以进入 UNAVAILABLE，不把这类场景算作自动居中精度。

## LDW 独立声音

此前 WARNING_ONLY 只有模式显示，没有实际声音入口。本轮将合法车道的预测边界接近接入声音；声音为三连双频短音，760 + 1140 Hz，单段 0.12 s、间隔 0.18 s，独立峰值增益 0.18。它不调用已有通用提示音，不依赖普通车辆提示音的音量标定，只共享已有 Web Audio 生命周期和输出总线。

报警有 2.5 s 冷却；持续同一次偏离不会反复播报，回到安全区域稳定 0.5 s 后才重新准备。对应转向灯、强驾驶员转向、低速、无效车道、交叉口、菜单/隐藏窗口及不支持的车辆均不会触发。只在 LDW / WARNING_ONLY 模式发声。
