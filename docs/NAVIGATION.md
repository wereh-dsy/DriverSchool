# 区域地图导航

仅菜单 **City Main · 区域高速网** 启用，地图源为 `src/world/regional/regional-main.json`。其他地图保留原有小地图行为。

- 点击独立小地图，或按 **F10** 展开；**Esc / F10** 返回驾驶。展开期间暂停仿真，取消巡航与 LCC 请求，关闭后不自动恢复这些驾驶功能。
- 拖动平移、滚轮以鼠标位置缩放；支持定位车辆、全图和加减缩放按钮。道路名称、高速编号、互通和服务设施来自现有地图元数据，标签避让重叠。
- 默认从当前位置出发。点击地图后确认道路层级和方向，再自动预览路线。也可先点击起点字段自由选起点；自选起点用于预览，开始导航会明确改从车辆当前位置重新计算。
- 设施选点绑定设施拥有的实际道路；上下层和不同方向的道路提供候选项，不把投影相交当作连通。
- 导航显示下一步动作、沿路线距离、下一道路、剩余路程和估算用时；持续偏航后重算。估算不含实时交通。到达判断同时检查道路进度、高度、距离和车速。
- 非沉浸模式提供独立导航提示；沉浸模式只保留支持车型的车内显示。导航规划面板仍可通过 F10 主动打开。
- 当前支持导航的 A6L、BMW 530Li、Golf GTI、Tesla Model 3、Taycan 车机借用同一份导航状态；有配套数字仪表的车型同时显示引导。P/R 页面及车辆警告保留各自优先级。
- 同地图切换车辆保留路线，切换地图清空路线。本轮不新增路线持久化、语音、交通服务或自动驾驶控制。

## 接入点

- `RoadNetwork.ts` / `CityRoadNetwork.ts`：路名、高速编号、显式有向端点连接和地点；路口路由遵守已编写的 approach movements，保留原有车道辅助连接。
- `RoutePlanner.ts`：空间索引、包含高度/方向的位置匹配、道路中段起终点和 A*；路口内部支持显式连接路径。
- `NavigationController.ts`：游戏级会话、5 Hz 进度与偏航重算，独立于 120 Hz 车辆物理。
- `NavigationMapPanel.ts` / `Minimap.ts` / `LocalRoadMap.ts`：大地图交互、小地图和共享路线绘制。
- `SharedVehicleData.navigation.guidance`：车机、仪表借用的会话状态。各显示适配器不拥有寻路或感知系统。
- `NavigationDisplay.ts` / `NavigationCenterDisplay.ts`：共享引导画法与既有中控屏的显示适配。无新增依赖或物理控制。

## 检查入口

`pnpm run selftest:navigation` 覆盖单行/反向道路、中段端点、高架隔层、转向限制、路口连接、偏航重算、四处服务区可达性，以及五款车辆的实际显示接入与静止刷新。导航与显示检查也已加入 `pnpm run selftest:systems`。完成代码修改后仍须运行完整 `pnpm run build`。

## 道路连续性修复

- 展开地图、小地图和车机复用 `LogicalRoadMapGeometry.ts`。绘制真实路口铺装轮廓，同层先统一描边再绘制路面，避免独立道路分段端帽产生横向接缝；隧道路面保持连续。
- 按道路局部高度分层绘制坡道和高架；路口裁切仅作用于所属道路，保留跨层道路。
- 检查发现 `urban-junction-85`、`urban-junction-96` 的偏斜 T 字路口中心原本位于铺装轮廓外。三维、物理支撑和路线使用中心扇形，而二维与道路所有权使用轮廓，造成源头不一致。`JunctionSurface.ts` 生成共享凸包时纳入中心，使所有使用者得到相同的铺装区域。
- `MapGeometryConsistency.selftest.ts` 检查全部 155 个路口、542 个入口、2489 条显式端点连接和 1585 处三维连续边缘。当前 9153 项断言通过，端点最大误差约 1.73 cm，连续铺装边缘误差为 0。
- 启动 `pnpm run dev` 后打开 `/scripts/navigation-map-selftest.html`，用真实 Canvas 像素检查五档缩放、路口入口、分段/高度层接缝、隧道和跨层遮挡。当前 5538 项断言通过，覆盖 1084 次区域地图入口检查。
