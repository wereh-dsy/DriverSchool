## 动力架构与接口

```mermaid
flowchart LR
  E[Engine + FuelSystem] --> K[K0 发动机解耦离合器]
  K --> S[P2 输入轴]
  B[HybridBattery] <--> M[ElectricMotor + 逆变效率]
  M <--> S
  S <--> H[9HAT 有效齿比与湿式换挡重叠]
  H <--> F[主减速 + 机械分动]
  F <--> D[原有前后差速器]
  D <--> W[原有四轮/轮胎/路面]
  G[AC/DC 外接输入] --> B
```

`P2HybridPowertrain` 扩展现有 ICE 生命周期和遥测适配器，复用 Engine、FuelSystem、Clutch、Gearbox、热状态和换挡建议；独立覆盖 P2 扭矩路径。EV 仍只安装原有 ElectricPowertrain。车型配置的 `hybrid` 决定动力拓扑，外观和车型名字不参与物理分支。

发动机有独立转速与惯量。K0 传递扭矩来自隐式双端惯量/滑差求解，容量按实际接合度限制；发动机接受同一扭矩作为反作用负载。**送入变速箱的是一次 `K0实际扭矩 + P2实际扭矩`，没有第二条发动机直达车轮路径。** 电机位于齿比前方，轮端扭矩经过 HAT、主减速和分动减速。

前进/倒车使用同一电机和机械负齿比。P/N 断开车轮支路，允许发动机带动自由旋转的 P2 输入轴发电；其旋转惯量仍积分，不能在 N 挡推动轮子。选挡沿用刹车/方向/转速联锁，低挡还会计入分动速比。`I` 控制混动车辆 READY；发动机自动停止不会使 `I` 失效。

9HAT 重用 AutomaticShiftController 和 SelectorSafety。它采用连续有效速比与湿式重叠扭矩容量的简化，**没有宣称复刻完整行星齿轮组或液压阀体**。与旧 AT 共用接口类型，但 P2 路径不安装假想的液力增矩源。电机补偿发动机实际输出不足及换挡容量降低；补偿同样经过当前齿比，受 400 Nm / 120 kW、电池和系统上限约束。换挡负载损失记为传动损耗；回收支路使用反向效率，避免“回收功率不变、车轮负载被换挡削弱”的能量漏洞。

## 能量管理与状态机

独立 `HybridEnergyManagement` 消费车速、输入轴速度、驾驶需求、SOC、电池可用充放电功率、发动机可用扭矩、换挡状态、刹车和燃油可用性；只输出策略请求，不改车速、车身姿态或轮胎力。

| 模式 | 策略 |
| --- | --- |
| EV | K0 断开、发动机停止；低于储备阈值才请求发动机接管。电池功率受限时如实降低纯电输出 |
| HYBRID | 高功率/高速/电机能力不足启动发动机；轻负载时按最低运行/停机时间退出，电机填补实际扭矩缺口 |
| SPORT | 有动力请求时预备发动机，发动机优先响应，电机补足；不会强制相加两个峰值 |
| CHARGE_HOLD | 目标可设 15–85%，默认 50%；低于目标的偏差决定发电请求，约 0.8% 死区 |
| CHARGE | 目标 80%；仅在有发动机剩余输出、足够转速、电池可充且不制动/换挡时发电 |
| REGEN 运行态 | 制动优先 P2 发电，余量由现有液压制动补足；它是实时运行态而非锁定的动力模式 |

启动/接合过程：`EV → STARTING → 发动机起动/转速同步 → K0渐进接合 → ENGINE/BOOST/CHARGE`。低 SOC 在 15% 触发、22% 解除，避免阈值抖动；最低运行 12 s、最低停机 3 s。开离合时仅用有界转速控制，接合过程中才逐渐引入驱动扭矩请求，避免空转超调。低速允许受容量约束的滑差起步，滑差做功作为损耗。

制动/松油门回收使用 K0 液压快速释放，避免发动机反作用与 ABS 释放冲突；正常接合仍是连续接合度。ABS 紧急限制可以比普通平顺性更快。状态名反映策略请求，发动机实际 phase、实际 K0 扭矩/接合度另行显示，不能把 BOOST 字样当作始终输出双源的证明。

发电功率最大 28 kW，但先受剩余发动机能力和可充功率限制。实际发电只来自负电机机械功；它作为负载经 K0 作用于发动机，FuelSystem 按实际燃烧扭矩/转速计油，包含发动机效率与电驱/电池损耗。低 SOC 持续高负载最终会耗尽电助力，届时功率自然回落至发动机可持续能力，不维持虚假 300 kW。

## 电池、充电与制动

`HybridBattery` 复用 BatteryPack 的储能、OCV、内阻、电流、端口限制、SOC 两端降额和 EVThermalState。新增的是充电连接与状态，不是第二套 SOC 算法。

- 储能单位 kWh，所有功率接口 W。`SOC = 储能 / 标定容量`。
- AC/DC 输入先乘充电器效率，再经过电池内阻与充电效率；`integrate` 按实际端口功率和 dt 更新能量。
- 状态为 DISCONNECTED / INHIBITED / CHARGING / COMPLETE，COMPLETE 使用 99.9% 容差并停止输入；不会强行把 SOC 设置到 100%。
- 外接充电要求停车、P、READY 关闭；连接时禁止启动和驱动。提供 `connectCharger(type, powerW?)`、`battery.disconnect()`，以及仅用于初始化/测试的 `initializeSOC`。
- 电池发热包括内阻和充放电损失，电机热状态来自实际转换损耗；低温/过热和低 SOC 限制放电，高 SOC/低温/过热限制充电。
- 回收为物理电机负扭矩。制动需求来自 BrakeTorqueCoordinator；前后轴任一 ABS 释放可切断共用 P2 回收，之后才在 `finishStep` 计入电池，液压制动补足。同一 P2 电机没有两个独立电池预算。
- SOC/燃油沿用原车型 ID 的低频保存键，未更换存储 schema。充电连接不跨重载保存。

## 四驱与越野边界

只有一条来自 HAT 的机械输出。2H 全部给后支路；AWD 根据前后载体轮速差连续增加/减少前支路份额；4H/4L 采用前后各半的等效耦合，4L 改变真实总速比。输入轴速度采用相同份额的前后载体速度，因此分配的机械功率能闭合。

前后轴沿用原 open Differential 与制动式 eDiff，胎面附着、接地/腾空、轴荷、纵横联合滑移、泥沙附加阻力均走已有物理。没有新增胎宽抓地倍率、越野抓地加成或姿态/速度纠正。

**现有四轮求解器不支持刚性中央轴等速约束、完整桥锁或后桥刚体多连杆运动。** 因此 4H/4L 遥测标为 `BOUNDED_50_50`、桥锁为 `NOT_SIMULATED`，它们不能保证原厂单轮着地脱困能力；交叉轴测试验证接触和数值稳定，不作为完整三把锁验证。车架为质量/惯量、长行程标定和可见梯形梁，不含车架扭转柔性。

NORMAL 是日常舒适响应，ECO 偏节能，SPORT 偏动力；WET 在此车型用于低附着/低速越野控制（更缓的踏板、低速转向响应和不同 TCS 阈值）。4L 另行选择。被动弹簧阻尼不会因模式虚构成空气悬架或 CDC。

外观是独立程序化车身/玻璃开口、格栅、灯组、保险杠/护板、侧踏、车顶行李架、尾门备胎、轮毂/实例化胎块；尺寸、轮心和碰撞使用同一配置。座舱有独立仪表/中控、棕色内饰和驾驶眼位；显示实际 SOC、K0/发动机 phase、电机/发动机功率、模式、分动状态及电池温度。材质不写入其他车型。

声音通过新的 Tank500AudioProfile 标定现有 EngineAudio，P2 电驱层作为附加层并行，不使发动机总线被纯电更新静音；发动机启动仍走原 ignition phase。是合成音，未采用原厂录音。未修改地图、天气或其他车型标定。
