# SU7 display fonts

These unmodified MiSans Latin Regular and Medium WOFF2 files were obtained from Xiaomi's official package:
https://hyperos.mi.com/font-download/MiSans_Latin.zip

Copyright belongs to Xiaomi. The original MiSans license is retained as `MiSans-LICENSE.pdf` and included in the playable package. Runtime credits identify MiSans Latin and link the bundled license.

Used only by SU7 driver/centre displays. No subsetting, conversion or modification of the font files.
