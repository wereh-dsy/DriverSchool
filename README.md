# DriverGame V0.2

一个可运行、可继续扩展的第一人称 3D 驾驶原型。项目使用 TypeScript、Three.js 和 Vite，所有世界尺寸与车辆参数均使用 SI 单位。

## 启动游戏（Windows）

最简单的方式是双击项目根目录里的 `start-game.cmd`。浏览器会自动打开；**游玩不需要预先安装 Node.js、pnpm 或其他开发工具**。

默认启动的是项目内已经打包好的完整游戏，因此离线也能运行。如果需要开发并实时查看源码修改，可以使用 `start-game.cmd -Dev`；只有开发模式才需要 Node.js 和项目依赖。

`pnpm run build` 先检查类型、执行回归验收，再在独立暂存目录打包。确认源码没有在检查期间改变后，先发布带哈希的资源，最后原子替换游戏入口；检查失败或中途停止不会覆盖可玩的上一版。旧资源与 `.checkpoint-builds/last-good-index.html` 保留用于恢复。双击入口始终使用最近一次成功发布的游戏包，不会尝试运行未验证的源码。

- 弹出的命令窗口在游玩期间需要保持打开；关闭窗口即停止游戏。
- 浏览器没有自动打开时，请打开启动窗口里 `Game address` 后显示的地址；通常是 `http://127.0.0.1:5173/`。
- 不要直接双击 `index.html` 或 `dist/index.html`；这个项目必须通过本地游戏服务运行。
- 若默认端口已被占用，打包版会自动尝试后续端口，并在窗口中显示实际地址。

页面打开后，点击“进入练习场”（也可以按 Enter）。MT 车辆按 `1` 挂入一挡并平稳给油；6AT / 7DCT 测试车踩住制动，在 F3 选 D，再松开刹车起步。

### 命令行启动

```bash
pnpm install
pnpm start
```

`pnpm dev` 仍然可用，但不会自动打开浏览器。

生产构建与类型检查：

```bash
pnpm run typecheck
pnpm run build
```

## 座舱仪表与车辆设置

家用轿车保留双圆形指针仪表，包含数字速度、挡位、油量、水温及必要状态灯；跑车改用独立的现代 GT 宽屏 TFT，以 40 段浅弧转速带、中央大挡位和数字车速为视觉核心，并用固定灯位呈现燃油、水温、灯光、手刹、发动机、电瓶与巡航状态。两套仪表均取消换挡建议灯，关键读数也经过方向盘遮挡检查。

左下方的离合行程条实时显示 `0—100%` 踏板位置，并标出半联动参考区。自动模式下它会弱化显示；切到手动离合后会高亮，便于用右摇杆小幅、缓慢地寻找结合点。

按 `F3` 或点击右下角“设置”可以：

- 在关闭、示廓、近光与远光之间切换；真实前后灯组同时驱动仪表和后视镜反射。雾灯在关闭主灯时会先开启示廓灯，关闭主灯也会关闭雾灯。
- 开关并保存“Controller Vibration”手柄震动设置；不支持震动的设备会安静跳过。
- 自动挡测试车可用独立 P / R / N / D 选择器；与实际 1—6 / 1—7 挡状态分开。
- 分别选择左右后视镜并上下左右调节镜片，设置会保存在浏览器中。调左镜时右上预览会临时切换为左镜。
- 选择当前地图和车辆；也可以在驾驶中用 `F4` / `F5` 快速轮换。切换后车辆会放到新地图的安全出生点，选择会自动保存。
- 点击任意驾驶键位后按下新按键完成改键；冲突键会自动交换，也可以一键恢复默认。自定义键位会持久保存，画面提示同步更新。

## 标准手柄

| 控件 | 功能 |
| --- | --- |
| 左摇杆 X | 转向 |
| RT / LT | 油门 / 制动（模拟量） |
| RB / LB | MT 升挡 / 降挡；AT / DCT 按 P→R→N→D 前进 / 后退一格 |
| A | 手刹开关（锁止 / 释放） |
| X | 跑车定速巡航开关（记录当前速度） |
| Y | 前后雾灯开关 |
| B | 保留，本轮无操作 |
| L3（按住） | 临时远光闪灯，松开恢复主灯状态 |
| R3 | 喇叭输入（预留声音接口） |
| 十字键 ← / → | 左 / 右转向灯开关 |
| 十字键 ↓ | 危险警示灯开关 |
| 十字键 ↑ | 关闭 / 示廓 / 近光 / 远光循环切换 |
| Start | 点火 / 熄火 |

普通模式下，右摇杆控制驾驶员左右、上下观察。按键盘 M 切到手动离合模式后，右摇杆完全交给离合：向下逐渐踩下，回中保持当前位置，向上逐渐松开。摇杆偏转量控制踏板移动速度，而不是直接映射踏板位置；小幅输入用于精确寻找半联动，大幅输入用于快速踩下或松开。MT 肩键仍是机械升降挡；AT / DCT 肩键改为 PRND 顺序选择，RB 沿 P→R→N→D，LB 反向，每次按下一格，长按不连跳，两端不循环。高速倒挡和驻车安全限制保留。地图/车型切换和设置不占手柄键。

手柄采用独立轴/踏板曲线，并支持运行中断开和重新连接。RT 油门使用 3% 死区、重新归一化及温和的 1.1 次方映射，前半程可用于细控；LT 制动保留原曲线。扳机只决定油门指令，发动机的时间响应仍由车型配置决定，不再用过强输入曲线压慢发动机。输入层最终只输出统一的 `VehicleInputState`，车辆动力学不会读取键盘、手柄或未来方向盘设备。

GT 跑车在前进挡且车速达到 `25 km/h` 后可按 X 记录当前速度并开启定速巡航；再次按 X 或踩刹车会退出。手刹、熄火、空挡/倒挡以及切入手动离合模式也会安全取消巡航。家用轿车不提供此功能。

手动离合模式下，如果挂挡且完全松开离合后把车刹停，发动机会被负载憋熄火；重新启动前需要挂空挡或把离合充分踩下。接合离合会让怠速出现可见的小幅掉转，半联动带动车辆的速度也受扭矩容量限制，高挡不能再依靠怠速起步。普通模式仍由自动离合在停车时及时分离，避免无意熄火。

## 车辆参数与操纵模型

车辆使用可扩展目录。家用前驱轿车的怠速为 `850 rpm`，保留温和的起步和动力链标定；约 `269 kW` 的后驱 GT 跑车采用 7 速变速箱、独立运动底盘、座舱、后视镜与 `280 km/h / 8000 rpm` TFT 仪表。外观渲染与物理计算分层，但车身、四轮、后视镜安装点和碰撞尺寸共享 `VehicleDimensions`。轿车是完整四门三厢造型，GT 保留低鼻宽体快背、扩散器、鸭尾和双排气。车辆配置包括发动机/离合/齿比、质量与重心、分轴制动、驱动形式、转向/Ackermann、轮胎抓地与滚阻、轻量悬挂及空气动力。详见下方 V0.2B/C。

发动机音效改为随转速、负载和车速连续变化的四层合成：排气点火脉冲、进气负载、机械运转与路噪/风噪。点火、发动机接合和熄火都有独立过渡，不再只是单一音高随转速变化。

转向不再让车头瞬间套用理想圆弧，而是经过方向机阻尼、车辆偏航惯量、前后轴侧偏刚度和轮胎抓地共同建立。车身朝向与实际速度方向可以短暂分离：拉起后轴手刹会降低后轮横向抓地并形成可控甩尾，松开后侧滑会逐步恢复。可在 `F2` 数据面板观察车身侧滑角、横向加速度和剩余后轴抓地。

路面采样也会影响车辆：沥青保持原始抓地和滚阻，压实路肩约为 `0.78×` 抓地、`1.7×` 滚阻，草地约为 `0.55×` 抓地、`3×` 滚阻，边界使用平滑过渡。坡道中心线和边线采用逐顶点贴地 ribbon，交叉口、斑马线和停车位线使用薄贴花，避免坡面悬空、厚重边缘和深度闪烁。

## 系统结构

### 车辆反馈与基本灯光

`VehicleLightingController` 是灯光状态唯一来源：示廓/尾灯、近远光、前后雾灯、制动灯、倒车灯和同步闪烁的转向/危险灯驱动真实 Exterior 灯体与座舱仪表。制动灯只读取制动踏板，倒车灯读取实际 R 挡与电气点火状态。转向灯以实际方向盘角度执行“超过 80° 后武装、回到 20° 中央区后取消”，小幅变道不会错误取消。

方向回正只作用于松开输入之后：停车弱、随车速平滑增强、接近中心放缓，前轮低抓地仅轻微减弱回正。它与主动打方向的响应、高速最大轮角衰减分开。

`VehicleFeedbackSystem` 只观察真实传动负载、离合滑差/接合速度与加速度变化，不注入车速或脚本式换挡摇摆。半联动反馈同时需要实际结合区、滑差、负载与较低转速，结合区使用当前车型离合参数；完全分离、空挡、正常完全接合不会因为低速产生离合震动。手动离合提供完整结合点反馈；自动离合正常起步保持平顺，仅异常负载与低转速时有克制反馈。手柄怠速震动已取消，座舱保留极微视觉发动机运动；半联动、濒熄火分开计算并平滑渐入/渐出，真正熄火和碰撞仍是独立短脉冲。

已有悬挂负责车身姿态，视觉和手柄共享机械反馈强度，额外视觉反馈仅为毫米级座舱微振，DriverEye、车身与镜面平面不另行抖动。`GamepadHaptics` 在设备层合并这些反馈并以约 30 Hz 更新；无支持设备、断开、关震动、打开设置或切后台时安静停止。实际手柄强弱仍应以玩家实机感受为准，可在 F3 关闭震动。

### MT 轻量机械细节

两辆 MT 在 Final Drive 到驱动轮之间加入短暂的传动换向缓冲：连续 lash 状态在发动机制动、卸载和驱动方向之间过渡，仅换向时减弱传扭，稳定加速/发动机制动恢复完整传递。家用车略柔和，GT 更紧致；重新受力的反馈复用已有 drivetrain jolt，不额外改变车速或模拟复杂传动轴。

收油并断开离合或卸载时，发动机可出现短暂 Rev Hang。它通过克制的残余发动机扭矩实现，仍遵守扭矩与转动惯量积分，不锁转速。家用车滞留较明显，GT 较弱；接合后的轮端负载、发动机制动和熄火行为优先。AT / DCT 不使用这两款 MT 的 Rev Hang 标定。

四轮驱动分配保持真实独立：家用车 FL / FR 各接收 50%，GT RL / RR 各接收 50%，非驱动轮扭矩为零。每轮最终力由自己的路面抓地约束；普通刹车和后轴手刹仍是独立路径，没有新增差速器限扭、LSD 或电子辅助。

F2 仅在调试面板显示 RT 原始/归一化值、油门指令与实际节气门、半联动各因子和震动强度，以及 lash、Rev Hang 和四轮驱动扭矩；正式驾驶界面不增加这些信息。

### MT / 6AT / 7DCT

现有家用 5MT 与 GT 7MT 通过兼容适配器保留原 Engine / Clutch / AutoClutch / Gearbox 核心结构与基础标定，新增机械细节作为轻量独立层。`TransmissionSystem` 统一输入输出与状态，但不读取具体设备。自动挡 selector P/R/N/D 与实际齿比挡位分开；高速 R/P 请求被拒绝，P 使用输出驻车约束而非巨大刹车力。

新增“6AT 测试轿车”和“7DCT 测试轿车”复用家用车几何，暂不代表正式品牌车型。6AT 初始齿比采用需求中给出的参考比例；7DCT 明确为可替换的测试标定，而非官方数据。液力 AT 的蠕行来自变矩器泵/涡轮滑差与怠速负载，扭矩倍率随速比收敛到 1；锁止渐进接合并在大油门/换挡/低速时退出。DCT 蠕行来自 A/B 摩擦离合，奇偶轴预选下一挡，换挡期间按各自齿比交接扭矩，没有复制 AT 锁止机构。

两种自动挡均使用配置化油门—转速换挡图、时间滞回和多挡安全 kickdown；真实传动负载回馈发动机转速与现有声音。F2 可查看类型、selector、实际挡位、换挡阶段、负载、AT 滑差/倍率/锁止或 DCT A/B/轴/预选。没有增加 S/M、拨片、CVT 或高级液压/热模型。

### Physics V0.2A：路面接触与静态碰撞

每个固定物理步分别查询四个轮子的世界位置、地面高度、单位法线及材质。`SurfaceMaterial` 统一定义沥青、混凝土、压实路肩、草地与路缘的纵向抓地、横向抓地、滚阻及粗糙度；地图边缘继续平滑混合。左右车轮的驱动、制动与滚阻独立计算，跨越路边时会出现温和的单侧拖拽。草地完全通过力自然减速，不直接修改车速。

制动与转向采用温和、连续的共同抓地衰减；家用车最大纵向需求仍保留约 72% 横向容量，跑车约 74%。两车原有动力链、输入、120 Hz 步长和起步标定继续保留。

`VehicleContactSystem` 编排逐轮采样和独立的 `VehicleCollisionSystem`。车身碰撞体使用随 yaw 转动的 OBB，尺寸来自外观配置的车身包络（含保险杠，不含后视镜），总长少 0.12 m、总宽少 0.06 m，并由外观测试检查尺寸一致性。护栏按视觉端点拆成最多 4 m 的短段，内部接缝不会充当阻挡擦墙的端面；墙体和建筑使用独立盒体，草地与高处屋顶不参与碰撞。扫掠分步、持续消除朝墙速度、小接触间隙以及仅在一次接触开始时施加的无反弹速度衰减，使正面碰撞基本停车、斜擦可缓慢滑动并退出。

F6 默认关闭，可查看四轮材质/法线/高度、车身框、附近障碍、接触点和法线。`pnpm run selftest` 包含两车三图接触验收、高速扫掠、持续压墙、退出碰撞以及 120 Hz 闭环连续两圈测试。V0.2A 阶段没有加入悬挂；下一阶段的轻量悬挂见下文。

### V0.2B：统一车辆几何与真实平面镜

`VehicleDimensions` 是车身包络、前后轮距、轴距、轮胎半径/宽度、镜架和碰撞框的共同来源。外观渲染与动力计算分层，但尺寸不再分离。家用车具备完整三厢四门轮廓、后翼子板/尾角、玻璃与柱子、真实开口轮拱和四轮；GT 保留低鼻宽体快背。视觉车轮世界位置直接读取物理四轮中心，车身俯仰侧倾后也不会另写一套轮位。碰撞 OBB 只比完整车身总长少 0.12 m、总宽少 0.06 m。

Exterior、Interior、MirrorSurface 独立分层，简化座椅归 Interior。驾驶相机可见全部正常视觉层；反射相机严格只渲染 WORLD + CAR_EXTERIOR，真实车身不再被隐藏，仪表、方向盘和镜面自身不会进入反射。

左右镜保留 DriverEye → MirrorPlane → reflected virtualEye，并用镜面四角建立非对称投影和斜裁剪。F3 调整镜片本身的朝向，不直接旋转反射相机。右上窗口继续复用实体镜的同一纹理，并从物理镜片四角映射显示方向，不使用假车身贴图、独立后向相机或任意二次水平翻转。旧版镜面校准会迁移清除，以免覆盖新默认角度。

默认角度优先近地面停车参考：家用车镜内约 18% / 17% 为真实车身，GT 约 16% / 16%，保留侧后车身、后轮附近和尾角。想看更远的后方道路可以用 F3 上调镜片。F7 显示尺寸边界、轮点、DriverEye、镜面四角/法线/虚拟眼，并在车后创建真实红左、白中、蓝右测试物件；关闭后全部隐藏。

### Physics V0.2C：四轮受力与轻量弹簧阻尼

动力链不变。Final Drive 后分配至实际驱动轴：家用车 FL/FR 前驱，GT RL/RR 后驱，同轴左右 50/50。普通制动力按车型前后偏置分到四轮；手刹只增加后轮制动力及后轮横向容量损失，不再人为添加甩尾增益。

各轮拥有独立位置、材质/法线、载荷、转角、驱动/制动/滚阻及横向力、弹簧压缩/速度。纵横向轮胎力平滑饱和，联合抓地衰减温和，保留刹车中调整方向的能力。近似载荷转移使用质量、重心、轴距和轮距，四轮载荷保持正值并守恒；接触耗散抑制持续饱和旋转，恢复抓地后滑动能逐渐收敛。

四个受支持的角质量采用已有弹簧、压缩/回弹阻尼和行程。四轮高度拟合接地平面，其余局部高度差进入各轮弹簧，不使用随机相机摇晃；平顶单轮凸起也不会丢失车身地面姿态。VehicleVisual 读取物理 heave/pitch/roll，家用车较软，GT 更硬、侧倾更小。模型仍是稳定的平面底盘加轻量悬挂，不模拟离地、完整刚体、复杂滑移率、Pacejka、ABS/TCS/ESC 或损伤。

`pnpm run selftest` 覆盖四轮驱动/刹车/后轮手刹、载荷方向与守恒、静止/低速/倒车、单轮高点及衰减、60/120 Hz 悬挂时间一致性、空挡接触阻力和发动机制动的区分，两辆车也各完成基础赛道连续两圈。开发模式下 `/validation.html` 提供真实第一人称验收按钮；它不会进入双击启动的打包版。

### 模块目录

- `src/vehicle/config`：独立的车辆物理配置，包含发动机扭矩曲线、齿比、主减速比、离合、制动、转向、空气动力学和轮胎参数。
- `src/vehicle/physics`：Engine → Clutch → Gearbox → Final Drive → Wheels → Vehicle 的力驱动动力链，以及四轮接触、载荷转移、弹簧阻尼和带偏航惯量的平面底盘。自动离合执行器与机械离合分离，保留后续扩展边界。
- `src/vehicle/visual`：与物理参数分离的座舱、车身、方向盘、车轮和实体后视镜。
- `src/camera`：真实 DriverEye 相机与平面镜反射系统。左右镜都使用 DriverEye 关于镜面反射得到的 virtualEye；右上角窗口复用右侧实体镜的同一个 RenderTarget。
- `src/world`：包含三张可切换地图。既有约 2.15 km 综合公路练习场和模块化科目二训练场继续保留；基础闭环试车赛道单圈约 `1.57 km`、宽 `9.5 m`、主直道约 `359 m`，使用 6 个半径 `45—110 m` 的清晰弯道，并设置路肩、草地缓冲、偏置护栏、起终点和小型 pit-like 停车区。闭环赛道只提供路线/路段元数据，没有计圈、比赛或检查点逻辑。
- `src/input`：键盘、标准手柄和未来方向盘设备的统一适配层，包含设备热插拔、按键边沿和手动离合速率控制。
- `src/game`：固定 120 Hz 物理步长、渲染、坡度采样和系统编排。

统一坐标系为 `+X` 向右、`+Y` 向上、`-Z` 向前；距离单位为米，速度为 m/s，角度在内部使用弧度。
