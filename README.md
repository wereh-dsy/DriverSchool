# DriverGame

基于 TypeScript、Three.js 和 Vite 的浏览器第一人称 3D 驾驶模拟项目。当前提供 **8 辆可切换车辆、8 个场地入口**、MT / AT / DCT / CVT 动力链、键盘与标准手柄操作，以及数据驱动的城市地图编辑器。车辆系统包含燃油与行程电脑、定速巡航、驾驶辅助，以及支持车型的 EPB、Auto Hold、自动启停和可变悬架；闭环测试场提供圈速计时。

物理以固定 **120 Hz** 更新，内部使用 SI 单位：距离为米、速度为 m/s、角度为弧度；坐标系为 `+X` 向右、`+Y` 向上、`-Z` 向前。仪表车速显示为 km/h。具体参数和行为以当前源码为准，测试车型与品牌风格车型不代表原厂精确数据。

## 启动与起步

### Windows 打包版

工程包含已构建的 `dist/index.html` 时，双击根目录的 **`start-game.cmd`** 即可启动本地服务并打开浏览器；游玩无需安装 Node.js 或 pnpm，也不需要网络连接。窗口需要在游玩期间保持打开，关闭窗口或按 `Ctrl+C` 会停止服务。

默认地址为 `http://127.0.0.1:5173/`。端口被占用时，打包版会尝试后续端口，以启动窗口的 `Game address` 为准。浏览器未自动打开时，手动访问该地址。

```powershell
# 不自动打开浏览器
.\start-game.cmd -NoOpen

# 指定起始端口
.\start-game.cmd -Port 5180
```

`dist/` 是构建产物，被 Git 忽略；新拉取的源码可能不包含打包版，此时需要先安装开发工具、依赖并执行 `pnpm run build`。不要直接双击根目录或 `dist/` 中的 `index.html`，游戏需要通过 HTTP 服务加载资源。

### 开发模式

需要符合 `package.json` 的 Node.js 版本（`^20.19.0 || >=22.12.0`）和 pnpm（项目声明 `pnpm@11.19.0`）。在项目根目录执行：

```powershell
pnpm install
pnpm start
```

`pnpm start` 启动 Vite 并自动打开浏览器；`pnpm dev` 启动开发服务，但不自动打开浏览器。Windows 也可运行 `.\start-game.cmd -Dev`，缺少依赖时该启动器会尝试安装，因此首次启动可能需要网络。

开发服务运行当前源码并支持热更新；普通 `start-game.cmd` 始终运行最近一次成功发布的 `dist/`。

### 第一次起步

1. 在欢迎界面选择场地和车辆，点击“进入练习场”或按 `Enter`。
2. 若发动机未运行，先在满足启动条件时按 `I` 或手柄 Start；A6L 初次进入时需要手动启动。
3. **MT：**默认普通模式由自动离合协助操作，按 `1` 挂入一挡，再逐渐给油。自动离合不代替驾驶员选择前进挡位。
4. **AT / DCT / CVT：**停车踩住脚刹，在 F3 选择 D，或用 `Q` / `E`、手柄 `LB` / `RB` 依次选到 D，再松刹车并给油。
5. 若驻车制动处于拉起状态，按 `Space` 或手柄 A 切换；支持 EPB 的车型也可在满足条件后给油自动释放。Auto Hold 保持时需要有意给油起步。按 `Backspace` 可回到当前场地起点，MT 回空挡，自动挡回 P。

所有自动挡的玩家 P / R / N / D 切换均要求脚刹输入至少 **10%**，手刹不能代替。行驶方向切换与 P 挡另有速度保护；正常自动升降挡和 CVT 变比不受选挡脚刹联锁限制。

### 山地试验与圈速计时

山地综合试验场使用独立的手工山路与连续地形，主环线之外还有技术支路。铺装、碎石、干土、湿土与冲沟通过地面高度、轮胎抓地、滚阻和粗糙度影响车辆，可用于对比 SUV 与公路车型；它不自动开启专用越野模式，也没有单独的任务或评分。

基础环形测试场的圈时 HUD 显示当前圈、上一圈和最佳圈。正向越过起终点后开始计时，按顺序通过检查点再回起终点才记录有效圈；逆向越线、漏检或异常瞬移会使当前圈无效。最佳圈按赛道与车辆 ID 保存在浏览器中，换车后读取各自记录。

计时使用仿真时间；打开设置或切后台时暂停，设置期间若车辆继续滑行超过允许距离，当前圈会作废。`Backspace`、切车或切图会重置当前计时，已保存最佳圈保留。

使用浏览器标准映射手柄，支持运行中断开和重新连接。按钮名称按 Xbox 布局表示。

| 控件 | 功能 |
| --- | --- |
| 左摇杆 X | 转向 |
| RT / LT | 模拟油门 / 脚刹 |
| RB / LB | MT 升 / 降挡；自动挡近静止踩刹车时 PRND，其余工况下支持的 AT / DCT 在 D 临时手动选挡；按住 RB 1 秒回自动 |
| A | 机械手刹 / EPB 开关 |
| X | 支持车型的定速巡航开关 |
| B | 支持车型的驾驶模式循环切换 |
| Y | 前后雾灯开关 |
| L3（按住） / R3（按住） | 临时远光闪灯 / 喇叭输入 |
| 十字键 ← / → / ↓ / ↑ | 左转向灯 / 右转向灯 / 双闪 / 主灯循环 |
| Start | 点火 / 熄火 |
| 右摇杆 | 普通模式观察；手动离合模式控制离合踏板移动速度 |

用键盘 `M` 切换到手动离合模式后，右摇杆向下逐渐踩离合、回中保持位置、向上逐渐松离合，水平输入不用于观察。小幅偏转适合找半联动，大幅偏转适合快速操作。左下离合条显示实际行程与结合区参考。

肩键选挡每次按下一格，不连续跳挡；PRND 在 P / D 两端不循环。自动挡只有车速低于 **2 km/h** 且脚刹至少 10% 时，肩键和 `Q` / `E` 才用于 PRND；否则仅在 D 且车型支持时请求机械挡位。CVT 不接受机械挡位请求，可用独立 PRND 键或 F3 选挡。支持临时手动选挡的车型按住 RB 1 秒，或等待车型配置的超时，即可回自动；红线和低转速保护仍有效。

RT 使用 3% 死区、归一化与 1.1 次方映射，LT 使用独立制动曲线；设备输入汇总为 `VehicleInputState`，动力学不直接读取浏览器设备。

定速巡航是实时驾驶功能，在前进挡、车速达到 **25 km/h** 且动力可用后记录当前速度；自动挡还要求 D。PI 闭环通过正常动力链补偿阻力和适度上坡，带积分限幅、防饱和和油门变化速率限制。驾驶员更大油门可临时覆盖，松开后恢复；再次按 V / X、踩脚刹、驻车制动、Auto Hold 保持、动力不可用、N / P / R 或手动离合模式会取消。超过目标约 5 km/h 后通过独立服务制动请求辅助下坡，ABS 保留最终权限；陡坡或动力不足不保证目标车速。V / 手柄 X 用于 SET / CANCEL，没有独立 RESUME 按键。

### EPB、Auto Hold 与自动启停

目前 A6L 与 Touareg 配有电子驻车制动、Auto Hold 和 Start/Stop，其他目录车辆使用机械手刹。三者各自有状态，Auto Hold 和 Start/Stop 的偏好在 F3 设置。

- **EPB：**停车挂 P 或人工熄火时自动施加；在 D / R、动力可用、松开脚刹并有意给油时自动释放，也可用 Space / 手柄 A 切换。执行器有施加与释放过程。行驶中主动施加请求受控的液压紧急制动，低速后转为驻车约束；机械手刹仍直接作用于后轮。
- **Auto Hold：**默认开启。D / R 近静止、踩刹车达到捕获条件后保持实际液压制动，松脚刹后继续支撑；有意给油且动力可用时渐进释放。自动启停停机期间继续保持，向 EPB 交接时等待驻车执行器完成。
- **Start/Stop：**默认关闭。开启后，在 D 近静止、无起步油门且脚刹或 Auto Hold 可靠保持一段时间后自动停机；车辆电源和附件保持工作。给油、切出 D，或没有 Auto Hold 时松开脚刹会请求重新启动。动力恢复前 Auto Hold 不抢先释放。人工熄火优先，空油箱不反复启动。

这些辅助通过正常动力链和制动扭矩工作，不固定车速或车辆姿态；坡道保持仍受轮胎与路面条件限制。

## 设置仪表与环境

F3 或右下角“设置”提供：

- **车辆与场地：**直接选择，浏览器保存最近选择。
- **环境：**晴天 / 小雨 / 大雨与白天 / 黄昏 / 夜晚自由组合，适用于所有场地；天气与时段选择会保存。
- **雨刷：**关闭、间歇、低速、高速；关闭时完成当前行程并回到停放位置。
- **灯光：**主灯与前后雾灯，状态同步到外部灯体、仪表和镜面反射；开雾灯会至少开启示廓灯，关闭主灯也会关闭雾灯。
- **驾驶辅助：**ABS / TCS / ESC 默认开启，Auto Hold 使用车型默认或已保存偏好，Start/Stop 默认关闭。偏好跨重生、换地图和重开保存，实际启用还要求车辆支持；不支持的选项不可用或隐藏。EBD 保持内建，不列为普通设置开关。Cruise 不属于持久 ON/OFF 设置。
- **油量与行程：**可编辑油箱余量；ODO、Trip A/B 按 vehicle ID 保存，约每 10 秒及退出 / 换车保存。距离以仿真速度积分，倒车和熄火滑行计入，暂停、瞬移和姿态重置不产生虚假里程。Trip A/B 可分别重置，普通重置不能清除 ODO。
- **自动挡：**独立 P / R / N / D 选择器；与 AT / DCT 的实际机械挡位、CVT 的连续传动比分开。
- **后视镜：**左右镜独立选择、上下左右调节与复位；调左镜时右上预览临时切为左镜，关闭设置恢复右镜。
- **小地图：**关闭、左上或右上，位置偏好保存。
- **手柄震动：**Controller Vibration 开关，不支持震动的设备会跳过。
- **改键：**点击驾驶动作再按新键；冲突时交换绑定，支持恢复默认，提示同步更新并保存。

设置面板会屏蔽油门、转向和驾驶快捷指令；自动挡仍接收脚刹，以便使用面板选挡。设置面板不会将驾驶场景变成静止预览，操作前宜先停车。

设置与编辑器草稿使用浏览器本地存储，按来源（协议、主机、端口）隔离；更换端口不会共享原设置。存储不可用时使用默认值，编辑地图可通过 JSON 导入 / 导出保留数据。

座舱具有车型独立的车身、内饰与仪表配置。辅助系统分别提供支持、启用和介入状态；关闭显示 OFF，介入指示短时闪烁。MT 有按负载计算的升挡建议，与红线警告分开。支持巡航的车型在 HUD 和对应仪表显示巡航状态及目标速度；高级仪表的 Cruise 信息页可通过 U 查看。

### 倒车接近提示

挂入 R 后，HUD 显示左后角、左后、正后、右后、右后角五个区域，以及最近障碍方向和距离；退出 R 后隐藏。高级仪表的 Parking 页复用同一检测状态，倒车影像仍按车型能力提供。

检测读取当前场地的真实静态碰撞体，并检查障碍物高度。后方区域探测约 3 m，角部约 1.8 m；超过 2.5 m 不高亮，1.5—2.5 m 为远距提示，0.8—1.5 m 为注意提示，0.4—0.8 m 为近距警示，小于 0.4 m 为红色紧迫警示。它只提供视觉信息，没有自动泊车、避障制动或探测蜂鸣音。

雨天包含降雨、挡风玻璃雨滴与雨刷清扫、湿路面视觉和抓地衰减。小雨湿度为 0.45，大雨为 1；湿路面材质系数与轮胎纵 / 横湿地保持率相乘，干路保持原系数。没有水滑、胎温、磨损或胎压模型。

## 车辆与场景实现

### 发动机与传动

`VehicleCapabilities` 仅描述支持性，结构能力来自真实系统配置；标定留在 subsystem config。`VehicleDynamics` 通过 `Powertrain` 抽象连接当前 `ICEPowertrain`，后者拥有发动机、燃油与传动；界面配置不决定物理拓扑。

`TransmissionSystem` 统一传动输入输出和状态。发动机支持 INLINE / V / W 布局元数据，当前目录使用直列四缸、直列六缸、V6 和 V8；缸数、排量、惯量与点火特征由配置提供。

- **发动机：**燃烧扭矩、节气门响应、怠速控制、机械摩擦、泵气损失与传动负载分别计算；涡轮车型另有涡轮转动、增压响应与泄压控制。发动机启动、运行和熄火状态参与动力链与声音反馈。
- **MT：**Engine → Clutch / AutoClutch → Gearbox → Final Drive。自动离合执行器与机械离合分离；手动模式支持半联动、负载掉转与憋熄火。车型可配置收油后的 Rev Hang 和传动换向间隙缓冲，稳定传扭恢复完整输出。
- **液力 AT：**变矩器滑差产生蠕行与扭矩放大，倍率随速比趋向 1；锁止渐进接合，并在相应工况退出。油门—转速换挡图结合时间滞回和安全 kickdown。
- **DCT：**A / B 摩擦离合、奇偶轴预选与按各自齿比交接扭矩；蠕行由离合产生，使用独立换挡标定。
- **CVT：**变矩器起步与锁止，按油门目标转速连续调节传动比；前进状态显示 D，不模拟 1—7 挡。
- **自动挡安全：**PRND 选择与实际传动比分离；P 为近静止时的输出驻车约束，高速方向切换和可能导致发动机超转的选挡会被拒绝。
- **Manual Selection：**支持的 AT/DCT 在 D 接受临时手动挡位请求，仍保留反拖、低转速保护和安全升挡；超时或按住手柄 RB 回自动。CVT 保持连续变比，MT 保持驾驶员选挡。
- **Start/Stop：**仅 A6L / Touareg 支持。D 近静止且脚刹或可靠 Auto Hold 保持一段时间后自动停机，车辆电源保持；油门或换向要求重新启动。Auto Hold 等 driveAvailable 才释放，空油箱不会循环尝试启动，人工熄火优先。
- **Fuel / Trip：**FuelSystem 计算燃烧用量、油量、燃油质量和续航。TripComputer 读取实际消耗增量，不重复模拟油耗；Trip A/B 的 operating time 为实际仿真时间（含停车），moving time 为速度绝对值超过 0.1 m/s 的时间。

### 四轮轮胎底盘与辅助

四轮具有持久轮速与旋转角，驱动、脚刹、后轮手刹和轮胎纵向反力共同积分。轮胎力随纵向滑移率、侧偏角、载荷和路面抓地变化，包含连续峰值 / 衰减、载荷敏感性与联合抓地约束；关闭 ABS 后重刹可以锁轮，近静止时有受抓地和制动扭矩限制的驻坡静摩擦。

开放式差速器对同轴两侧等扭矩分配，GT / 458 的后轴 LSD 根据配置有限偏置扭矩；A6L / Touareg / 458 的 eDiff 通过制动协调器请求轮端液压制动。FWD 驱动前轴，RWD 驱动后轴，AWD 先分配前后轴再进入差速器；适时 AWD 根据油门与前轮滑转平滑改变分配，不强制锁定轮速。

转向通过方向盘角度、转向比和 Ackermann 建立前轮角，主动响应、松手回正和高速转向权限分别配置。平面底盘包含偏航惯量、侧偏与载荷转移；四角轻量弹簧阻尼悬挂读取实际地面高度，包含压缩 / 回弹阻尼、渐进限位与前后机械防倾杆，输出 heave / pitch / roll 给车身视觉。

空气动力保留原有 Cd / area / air-density 风阻，前后 Cl 独立产生随速度平方变化的垂直力：正值升力减少载荷，负值下压力增加载荷。载荷进入悬架弹簧与实际轮胎法向载荷，自然改变纵横抓地，不直接乘抓地系数。道路车标定克制，GT 有轻微前后下压力。

轮胎 preset 只填充现有 TireConfig：海腾 S1 comfort touring，Sylphy eco touring，Mazda / Sagitar sport touring，A6L premium touring，Touareg SUV road，GT / 458 performance；AWD 测试 fixture 沿用 6AT 的 sport touring。胎宽不自动提高摩擦系数。A6L / Touareg / 458 的自适应阻尼平滑响应模式；Touareg 空气悬架缓慢修改真实 rest geometry，轮位、车身与碰撞高度共同读取悬架结果。

驾驶辅助使用真实轮胎和底盘状态干预：ABS 调节各轮液压制动压力，EBD 调整前后分配，TCS 在驱动滑转时削减发动机扭矩，ESC 根据偏航与侧滑请求单轮制动。脚刹、巡航、ESC、eDiff、Auto Hold 和 EPB 动态制动的服务制动请求统一经过 `BrakeTorqueCoordinator`，ABS 保留最终调节权限；机械后轮手刹独立于 ABS。

TCS / ESC 阈值、介入力度和响应由车型配置控制；A6L / Touareg 采用较早且稳健的标定，GT 允许更多滑移后介入。关闭其中一项不关闭其它辅助，也不取消正常巡航功能。

### 接触碰撞与统一几何

`VehicleContactSystem` 每个物理步采样四轮世界位置、地面高度、法线与材质；沥青、混凝土、压实路肩、草地、路缘及山地碎石 / 干土 / 湿土分别提供抓地、滚阻与粗糙度。路边平滑过渡，左右轮独立受力。城市高架通过支持高度区分地面和上层路面，并沿连续坡道衔接。

静态碰撞使用随车身 yaw 旋转的 OBB、扫掠分步和接触速度约束，支持墙体、建筑与护栏的正碰、擦碰和脱离。`VehicleDimensions` 统一车身包络、轮位、轴距、轮距、轮胎尺寸和镜架；碰撞尺寸来自外观配置，车轮视觉读取物理四轮中心。

### 后视镜与反馈

左右实体镜以真实 DriverEye 关于镜面反射得到 virtualEye，通过镜面四角建立非对称投影与斜裁剪。反射只渲染世界与车辆外观，不包含座舱仪表、方向盘和镜面自身。F3 改变镜片方向，右上预览复用实体镜纹理；F7 / F8 可检查尺寸与反射几何。

车辆反馈读取离合滑差、传动负载、加速度变化与碰撞，形成半联动、濒熄火、熄火和传动冲击反馈；不通过脚本直接改车速。悬挂控制主要车身姿态，附加座舱微振幅度受限，手柄反馈约 30 Hz 更新。断开设备、关闭震动、打开设置或切后台时停止震动。

发动机声音由排气点火、进气负载、机械运转及路噪 / 风噪层合成，随转速、负载与车速连续变化，包含启动和熄火过渡。喇叭目前仅提供输入接口。

支持自动折叠镜和氛围灯的车型由外观配置驱动附件；高级信息页与倒车影像只读取场景和车辆状态，不决定底盘或动力链能力。

## 城市地图编辑与数据工具

### 启动编辑器

通过开发启动器运行编辑器需要 Node.js 和已安装的项目依赖。Windows 双击 **`start-editor.cmd`**，或在项目根目录执行：

```powershell
pnpm run editor

# 不自动打开浏览器，并指定起始端口
pnpm run editor -- --no-open --port 5180
```

启动器打开 `?editor=city`，会复用已有 DriverGame 开发服务，或在 20 个候选端口中选择可用端口。Windows 启动脚本会查找现有的受支持 Node.js 安装。已有开发服务也可直接访问 `http://127.0.0.1:5173/?editor=city`，端口按实际服务替换。编辑器界面也包含在生产构建中，已启动打包版时可在其服务地址后加 `?editor=city` 打开。

### 编辑与试玩

- **Top：**左键选择 / 放置，拖动节点修改 X/Z，拖动对象或道路移动；中键 / 右键拖动平移，滚轮缩放。
- **Road：**选择道路样式与车道类型，点击节点后按 Enter 或 Finish；可开启网格、端点和路口端口吸附。
- **Inspector：**修改宽度、限速、方向、人行道、位置、旋转和节点 XYZ；支持 Ground / Elevated / Custom 高程、护栏与桥墩。
- **Preset / Stamp：**道路、互通和街区预设，带参数与线框预览；`R` 每次旋转 15°，可用暴露端口继续连接道路。
- **Prefab：**放置低多边形建筑与路边设施，编辑旋转、缩放和颜色。
- **3D：**左键轨道观察、右键平移；实际编辑在 Top 模式完成。
- **Undo / Redo：**保留 64 个历史快照。Validate 给出结构化错误与警告，无效操作回滚；道路推荐坡度不超过 12%，超过 25% 会拒绝。

完成的编辑自动保存同一来源的浏览器草稿，未完成的 Road 草稿不保存。Reload City Alpha 重新读取当前内置 JSON；Open / Import 可导入其他 JSON，Save / Export 下载可移植地图文件。

**Play in Game** 验证并保存当前地图，通过 `?city=editor` 打开游戏；正常场地菜单也可以选择“自定义城市道路”。浏览器草稿不会自动覆盖源码 JSON。要更新内置 City Alpha，将导出的数据写入 `src/world/city/maps/city-alpha.json`，验证后重新构建。

### 地图 CLI 与数据约定

```powershell
pnpm map summary city-alpha
pnpm map validate src/world/city/maps/city-alpha.json
pnpm map list-presets
pnpm map validate-presets
```

`pnpm map` 支持 `city-alpha`、`city-main` 和 `preset-showcase` 文件别名，还支持 `place-preset`、`add-road`、`move-node`、`connect-road`、`place-prefab` 和 `delete-object`。修改命令默认覆盖输入文件，`--out` 可写到其他文件；`--request '@request.json'` 适合 Windows 下传入结构化参数。验证错误退出码为 1。

CityMap V2 的 JSON 保存道路、路口、物件、显式 `roadLinks`、连接端口和出生点。道路可为地面、统一高架或逐节点自定义高度；预设展开成普通可编辑元素。仅在平面投影交叉的道路不会自动连通，尤其高架上下层需要保留独立拓扑。

MapAPI 的 `splitRoadAtPoint` 可显式拆路并保留或重映射外部连接、路口和暴露端口；GUI 不在交叉处自动插入路口。预设放置验证临时片段与合并后的地图，错误阻止保存，警告保留供检查。

道路设施体验场可通过场地菜单或 `?city=preset-showcase` 打开，追加 `&preset=<production-id>` 选择对应设施出生点。City Main 是独立的地图数据文件，可通过编辑器 Import 和 Play 试玩，当前菜单默认城市仍使用 City Alpha。

地图位置使用米、JSON 旋转使用弧度、限速使用 km/h；CLI 的 `--rotation` 参数单独使用角度。城市按扇区加载视觉资源并使用实例化物件；道路网络、路面采样和碰撞数据保持可查询，不随远处视觉卸载失效。

## 当前范围与常见问题

当前物理采用平面底盘与轻量四角悬挂，尚未模拟完整六自由度刚体、离地飞行、车辆损伤或复杂轮胎 / 液压 / 热模型。开放式差速器、LSD、eDiff、AWD、AT/DCT 临时手动选挡已实现，没有独立 S / M 选择器位置。没有 LKA、ACC、Hybrid / EV、主动空气动力、胎温 / 磨损 / 水滑或越野模式。

城市道路提供信号灯与路网元数据，闭环测试场提供单车圈速记录；尚无 AI 交通、行人、自动寻路、考试评分、比赛或多人模式。城市编辑器支持道路高程、基础设施预设和 API 显式拆路，尚无 GUI 自动拆路、完整 CAD 约束、隧道内部或 GUI 直接覆盖本地文件的流程。倒车提示和影像不执行自动泊车或避障制动。

| 问题 | 检查方式 |
| --- | --- |
| 双击提示 packaged game missing | 确认 `dist/index.html` 存在；缺失时安装依赖并执行 `pnpm run build` |
| 修改源码后打包版没有变化 | 完成 `pnpm run build` 后刷新；开发时使用 `pnpm start` 或 `-Dev` |
| 浏览器打不开 / 默认端口被占用 | 查看启动窗口实际地址，或指定其他端口；保持服务窗口打开 |
| 无法启动 3D 场景 | 使用支持 WebGL 2 的浏览器，启用硬件加速；详细错误见浏览器控制台 |
| 自动挡不接受 D / R / P | 踩住脚刹至少 10%，方向切换或 P 挡还需满足速度限制；手刹不代替脚刹 |
| MT 熄火后无法启动 | 先挂 N 或充分踩离合，再按 I / Start；检查手刹与离合模式 |
| A6L 进入后没有动力 | 在 P / N 按 I / Start 并等待启动完成；检查油箱余量、EPB 和 Auto Hold |
| 松脚刹后车辆仍保持停止 | 查看 Auto Hold 与 EPB 状态；支持车型有意给油且动力恢复后才释放 |
| 发动机停车后自动停机 | 检查 F3 的 Start/Stop；自动停机保留电源，符合重新启动条件后恢复 |
| 肩键没有切换 PRND | 停到低于 2 km/h 并踩住脚刹至少 10%；行驶中 D 挡的肩键可能用于临时手动挡位 |
| 圈时不记录或回到等待状态 | 选择基础环形测试场，正向越过起终点并按顺序通过检查点；重置或设置期间滑行会使当前圈无效 |
| 设置或编辑地图换端口后消失 | 浏览器本地存储按来源隔离；回到原地址，地图通过 Export / Import 转移 |
| 小地图未显示 | 在 F3 开启，并选择科目三或 City 场地；其他场地未提供道路网络 |
| 手柄没有震动 | 检查浏览器 / 手柄震动支持与 F3 开关；设置面板打开或切后台会停止震动 |
